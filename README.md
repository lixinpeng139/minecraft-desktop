# Minecraft 桌面

把 Windows 桌面变成 Minecraft Java 版的界面。所有贴图、字体、音效和中文文本都直接读取自本机安装的 Minecraft（不随项目分发）。

下载安装包：[Releases](https://github.com/lixinpeng139/minecraft-desktop/releases/latest)（Windows 10 / 11 x64）

## 使用

| 操作 | 效果 |
|---|---|
| 底部快捷栏 | 代替任务栏的 Dock。左键/右键点击启动，滚轮或 1–9 切换选中格，点空格子打开物品栏；可以直接从资源管理器把文件拖进格子 |
| `E` | 打开/关闭物品栏（创造模式物品栏样式） |
| `T` | 打开聊天栏（显示桌面状态） |
| `/` | 打开聊天栏并输入命令 |
| `Esc` | 游戏菜单（进度、统计信息、选项…、对局域网开放、保存并退回到标题屏幕） |
| `Enter` | 启动快捷栏中选中的物品 |
| `F3` | 调试屏幕（时间、CPU、内存、电池） |
| `Win + D` | 其他窗口挡住桌面时，用它回到桌面，再按 `E` |

物品栏里：

- 单击拿起物品，再点击快捷栏格子放下（也可以直接拖过去）；按住 Shift 单击直接放进快捷栏；悬停时按 1–9 放进对应格子
- 双击或右键：打开文件
- 拿着物品点击自定义标签页（或在该标签页的网格里放下），就把它归入这个分类
- 把物品拖到物品栏外面 / 悬停按 `Q`：从快捷栏或当前分类中移除（不会删除文件）
- 指南针（搜索）和箱子（所有物品）两个标签页固定；其余最多 12 个标签页的名称和图标可在“选项… → 标签页设置…”里增删、编辑、排序，图标可从约 100 个原版物品/方块中选择，也可以用自己的图片

“选项…”中还有：界面尺寸（与游戏相同的自动/1–6 倍）、开机自动启动（默认开）、桌面背景（全景图/系统壁纸/自定义图片）、全景图滚动速度、菜单背景模糊程度、物品图标样式、音量、按键绑定、隐藏任务栏/桌面图标、为快捷栏预留屏幕空间等。

关闭“隐藏任务栏”后，快捷栏会自动移到任务栏上方，跟着任务栏的高度和位置变化；这时不再为快捷栏预留屏幕空间，最大化的窗口会一直贴到任务栏并把它盖住（所以“为快捷栏预留屏幕空间”只在隐藏任务栏时有效）。开启“隐藏任务栏”时保持原样：快捷栏贴在屏幕最底部，最大化窗口停在它上方。

## 生命值、饱食度和经验条

快捷栏上方和原版生存模式一样显示生命值、饱食度和经验条。它们画在桌面上，打开的窗口会把它们挡住（快捷栏仍在最上层）。

- 生命值 = 电量：每 5% 半颗心（1–5% 半颗，6–10% 一颗……96–100% 十颗）。台式机没有电池，一直满血。充电时有生命恢复的波浪动画；电量下降时掉的心会闪烁；只剩两颗心以下时会抖动
- 饱食度 = CPU 占用：空闲时是满的，占用越高越少；占用超过 50% 时图标会抖动，越饿抖得越频繁
- 经验条 = 正在播放的声音：随声音的峰值跳动，变小时逐渐回落（与系统音量设置无关）

## 聊天栏

任务栏隐藏后，在桌面按 `T` 打开聊天栏，原来任务栏上的信息会显示在聊天记录的位置，和原版聊天消息一样可以点击、悬停查看详情：

- 时间和日期：点击打开通知和日历
- 网络、电量：点击打开快速设置 / 电池设置
- 音量、亮度：点击 `[-]` `[+]` `[静音]` 调节，或在数值上滚动滚轮
- 后台程序（有通知区域图标、没有窗口的程序）：点击打开
- 窗口：点击标题切换过去，`[_]` 最小化，`[×]` 或中键关闭

按 `/` 可以直接输入命令，`Tab` 补全，上下方向键翻看输入过的内容。输入 `/help` 查看所有命令：

| 命令 | 作用 |
| --- | --- |
| `/volume <0-100\|+N\|-N\|mute\|unmute>` | 设置音量 |
| `/brightness <0-100\|+N\|-N>` | 设置屏幕亮度 |
| `/tp <编号\|窗口标题>` | 切换到窗口（编号就是聊天栏里窗口前面的数字） |
| `/minimize <编号\|窗口标题>` | 最小化窗口 |
| `/kill <编号\|窗口标题>` | 关闭窗口 |
| `/settings [页面]` | 打开快速设置，或 sound、display、network、battery 等设置页面 |
| `/time` | 显示日期和时间 |
| `/clear` | 清空聊天记录 |

“后台程序”是根据通知区域图标的注册记录和正在运行的进程判断的，可能和真实托盘略有出入。原来 `T` 打开的“搜索物品”现在默认不绑定，可在“选项… → 控制… → 按键绑定…”里设置。

## 安装

从 [Releases](https://github.com/lixinpeng139/minecraft-desktop/releases/latest) 下载最新的安装包（`Minecraft-Desktop-x.y.z-Setup.exe`，下载列表里显示为“Minecraft桌面-x.y.z-安装包”）并运行。安装后在开始菜单的“Minecraft 桌面”文件夹里有三个快捷方式：启动、退出、恢复任务栏和桌面图标。

首次启动会自动从 Mojang 官方服务器下载界面资源（约 30 MB，只需要一次），窗口里会显示进度、下载速度和剩余时间。连不上官方服务器时会自动改用 BMCLAPI 国内镜像；下载失败可以点“重试”。

资源保存在 `%APPDATA%\minecraft-desktop\assets`。安装包里不包含任何 Mojang 的文件。如果资源损坏，可以在“选项… → 桌面设置… → 重新获取游戏资源…”里重新下载。

退出程序或卸载时会恢复任务栏和桌面图标，卸载时还会移除开机启动项。万一任务栏没有回来，运行开始菜单里的“恢复任务栏和桌面图标”。

## 从源码运行

- 启动：双击 `启动 Minecraft 桌面.vbs`（或 `npm start`）
- 退出：游戏菜单 → 保存并退回到标题屏幕 → 退出游戏；或双击 `退出 Minecraft 桌面.vbs`
- 恢复：`恢复任务栏和桌面图标.vbs`
- 首次运行前先用 `npm run extract` 把资源下载到项目内的 `assets/`

## 开发

- `npm run dev`：不改动任务栏/桌面图标/开机启动
- `npm run dist`：生成安装包（国内网络可设置 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`）
- `npm run test:capture`：在不可见窗口中依次打开所有界面并截图到 `.dev/shots/`
